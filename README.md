# ✨ 별가루 키우기 (Stardust Idle)

귀여운 2D 우주 클릭커 방치형 게임! 별을 콕콕 눌러 별가루를 모으고, 우주 친구들을 고용해 자동으로 별가루를 수확하세요.

## 🎮 플레이 방법

`index.html`을 브라우저에서 열기만 하면 됩니다. 설치·빌드·서버 전부 필요 없어요!

- **👆 별 클릭 / 스페이스바** — 별가루 획득
- **🏭 시설 탭** — 아기 별, 우주 토끼, 꼬마 로켓 등 10종의 자동 생산 시설 구매
- **⬆️ 업그레이드 탭** — 클릭 파워 강화, 시설 생산량 배수 업그레이드
- **💤 방치 보상** — 게임을 꺼도 최대 8시간까지 오프라인 수익 지급 (50% 효율)
- **📤 백업 / 📥 복원** — 세이브 코드를 복사해 두었다가 다른 기기·브라우저에 붙여넣으면 이어서 플레이
- **☁️ 구글 시트 동기화** — 내 구글 시트를 무료 클라우드 저장소로 사용, 어느 기기에서든 닉네임+비밀코드로 이어하기
- **💥 초신성 환생** — 누적 100만 별가루부터 환생 가능, 🌟 별의 정수 1개당 모든 획득량 +2% 영구 보너스
- **☄️ 골든 혜성** — 90초~4분마다 화면을 가로지르는 혜성을 클릭하면 대량 별가루!
- **🗺️ 우주 항해 지도** — 스테이지를 정복하며 미지의 세계로! 12개의 테마 지역 이후엔 무한 절차 생성. 스테이지마다 배경이 바뀌고 생산 +5% 영구 보너스
- **🏆 업적 20종 & 📊 통계** — 기록 탭에서 확인, 업적 1개당 생산 +1% 보너스
- **🔊 효과음** — WebAudio로 합성한 클릭·구매·혜성·환생 사운드 (토글 가능)
- **⭐ 레벨 & 스탯** — 클릭·방치·혜성·스테이지로 경험치를 모아 레벨 업, 힘/지혜/행운/매력에 포인트 분배 (환생에도 유지)
- **🎲 클릭 크리티컬** — 행운 스탯에 비례한 확률로 ×10 대박!
- **🗡️ 우주 유물 16종** — 혜성·업적·새 지역에서 드랍되는 4등급 장비, 슬롯 3개에 장착해 빌드 구성 (은하수 숟가락부터 전설 초신성 검까지)
- **🚀 원정** — 우주 친구들을 15분~4시간 탐사에 파견, 게임을 꺼도 진행! 별가루·유물·펫·행성·정수를 들고 귀환
- **🐾 펫 6마리** — 원정에서 만나는 동료, 먹이로 교감을 쌓으면 효과 강화, 활성 펫이 별을 졸졸 따라다녀요
- **🌍 행성 도감 12종** — 원정에서 발견해 수집, 행성당 생산 +1% + 도감 완성 보너스
- **👾 보스 운석 레이드** — 30초 안에 클릭 연타로 파괴! 성공 시 대량 별가루 + 유물 확정
- **📜 일일 퀘스트** — 매일 3개, 완료하면 1시간치 별가루 + 경험치
- **🌠 유성우 이벤트** — 랜덤 타이밍에 30초간 생산 ×7 대폭발!
- **🎨 별 스킨 6종 & 🌌 배경 테마 4종** — 환생·보스·도감 달성으로 해금하는 꾸미기 (성장 탭)
- **📱 PWA** — GitHub Pages 등 https로 서빙하면 홈 화면에 설치해 앱처럼 + 오프라인 플레이

> `index.html` 하나로 모든 게임이 돌아가요. `manifest.webmanifest`·`sw.js`·`icon.svg`는
> 홈 화면 설치(PWA)를 위한 선택 파일이라, 없이 열어도 게임은 완전히 동작합니다.

> 앞으로의 확장 계획은 [ROADMAP.md](ROADMAP.md)를 보세요 — RPG 스탯, 유물 장비, 원정, 보스 레이드로 계속 커집니다.

## ☁️ 클라우드 저장 설정 (최초 1회, 약 5분)

내 구글 계정의 시트 하나를 세이브 저장소로 쓰는 방식이라 회원가입도, 비용도 없습니다.

1. [sheets.new](https://sheets.new) 로 새 구글 시트를 만듭니다 (이름은 아무거나, 예: `별가루 세이브`)
2. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다
3. 편집기에 기본으로 있는 코드를 지우고, 이 저장소의 [`google-apps-script/Code.gs`](google-apps-script/Code.gs) 내용을 전부 붙여넣고 저장(💾)합니다
4. 오른쪽 위 **배포 → 새 배포** 를 누릅니다
   - 유형 선택(⚙️)에서 **웹 앱** 선택
   - "액세스 권한이 있는 사용자"를 **모든 사용자** 로 설정
   - **배포** 클릭 → 권한 승인 (내 계정 선택 → "고급" → "이동" → 허용)
5. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다
6. 게임에서 **☁️ 동기화** 버튼을 누르고 URL, 닉네임, 비밀코드를 입력하면 끝!

이후에는 아무 기기에서나 같은 URL + 닉네임 + 비밀코드를 입력하면 이어서 플레이할 수 있어요.
"자동 저장" 체크박스를 켜면 3분마다 + 게임 종료 시 자동으로 클라우드에 저장됩니다.

> ⚠️ 웹 앱 URL을 아는 사람은 누구나 세이브를 쓸 수 있는 간단한 구조예요 (비밀코드는 SHA-256 해시로 저장).
> 게임 세이브 용도로는 충분하지만, URL을 공개된 곳에 올리지는 마세요.

## ✨ 특징

- 순수 HTML/CSS/JS 단일 파일 — 의존성 0개
- SVG로 그린 귀여운 별 캐릭터 (클릭하면 웃어요!)
- 반짝이는 별 배경, 클릭 파티클, 궤도를 떠다니는 우주 친구들
- 한국식 숫자 표기 (만 / 억 / 조 / 경)
- localStorage 자동 저장 (15초마다 + 종료 시)
- 모바일 세로 화면 대응 반응형 레이아웃
